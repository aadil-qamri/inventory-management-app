# 📦 Inventory Manager | Streamline Your Stock

A modern, highly responsive, full-stack inventory management dashboard built to track stock, visualize financial analytics, and manage products efficiently. 

![Dashboard Preview](/public/myApp.png)

## ✨ Key Features

* **Secure Authentication:** Protected routes and seamless login flows powered by `NextAuth`.
* **Dynamic Dashboard:** Real-time summary cards tracking total products, low stock alerts, and total inventory value.
* **Flawless CRUD Operations:** Instantly Add, Edit, and Delete inventory items via sleek, responsive modal forms.
* **Advanced Analytics:** Toggleable data visualization (Bar & Donut charts) and granular Profit/Loss tracking powered by `Recharts`.
* **Data Portability:** One-click CSV export functionality to download your inventory database instantly.
* **Premium UI/UX:** Fully responsive design with native Light/Dark mode toggling, built with Tailwind CSS and Radix UI primitives.

## 🛠️ Tech Stack

* **Framework:** [Next.js (App Router)](https://nextjs.org/)
* **Language:** TypeScript
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Authentication:** [NextAuth.js](https://next-auth.js.org/)
* **Components:** Custom UI components (inspired by shadcn/ui) & Lucide Icons
* **Data Visualization:** [Recharts](https://recharts.org/)
* **Table Management:** TanStack React Table
